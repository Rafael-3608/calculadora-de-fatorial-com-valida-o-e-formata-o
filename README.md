# Calculadora de Fatorial

Repositório contendo exercícios práticos e algoritmos desenvolvidos em Java para fixação de lógica de programação, estruturas de repetição e manipulação de strings.

# Funcionalidades

- **Calculadora Fatorial:** Cálculo matemático de fatoriais com validação de entrada de dados.

# Tecnologias Utilizadas

- **Linguagem:** Java
- **IDE:** VS Code 
- **Controle de Versão:** Git e GitHub
